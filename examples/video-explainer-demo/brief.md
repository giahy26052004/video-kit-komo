# Canonical demo brief

Create a 20–30 second reviewed vertical explainer for a technical creator.

The video should show one idea: expensive narration and rendering start only after an independent review checks facts, structure, duration, visual feasibility, privacy, and copyright. Keep the example neutral, use only repository-owned text and shapes, and do not upload anything.

Success means a local 1080×1920 MP4, a script-bound review receipt, and a verification report. The macOS `say` voice is explicitly demo-quality.
