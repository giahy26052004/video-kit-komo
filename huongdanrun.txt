1. AUTO AI VIDEO PIPELINE (video AI/công nghệ/crypto từ GitHub trending)
===============================================================
- File: scripts/auto_pipeline.mjs, workflow: .github/workflows/auto-pipeline.yml
- Nội dung: research GitHub/HackerNews trending -> viết script (KomoAPI LLM)
  -> render Remotion -> đăng Facebook Reels (Page KOMO AI) -> comment quảng
  bá KomoAPI tự động dưới mỗi video.
- Bật lại:   gh workflow enable "Auto AI Video Pipeline"
- Tắt:       gh workflow disable "Auto AI Video Pipeline"
- Chạy tay:  node scripts/auto_pipeline.mjs [--dry-run] [--skip-publish]
- State chống trùng: data/auto-pipeline-state.json

===============================================================
NẾU MUỐN BẬT LẠI GITHUB ACTIONS CHO YOUTUBE (dùng cookie)
===============================================================
1. Cài extension trình duyệt "Get cookies.txt LOCALLY", đăng nhập YouTube,
   export cookie domain youtube.com ra file cookies.txt.
2. Đưa file cho Claude Code (qua đường dẫn file, không dán nội dung vào chat).
3. Claude nạp vào GitHub Secret (vd YOUTUBE_COOKIES_B64), sửa
   scripts/youtube_downloader.mjs thêm --cookies <file> cho yt-dlp, sửa
   .github/workflows/youtube-pipeline.yml giải mã secret ra file trước khi
   chạy, rồi bật lại: gh workflow enable "Auto YouTube Reup Reels"
   (nhớ tắt task Task Scheduler nếu chuyển hẳn qua GitHub Actions, tránh
   đăng trùng 2 nơi cùng lúc).
Lưu ý: cookie có thể hết hạn sau vài tuần/tháng, cần xuất lại.

gh secret list                      # xem tên các secret đã có (không xem được giá trị)
